# Golden Notch

Application macOS pour votre encoche.

[Télécharger la dernière version](https://github.com/pierreburnn/golden-notch-releases/releases/latest)

Ce dépôt contient uniquement les téléchargements et le flux de mises à jour. Le code source est privé. Aucun compte GitHub ni token n’est nécessaire pour télécharger ou mettre à jour l’app. Les archives de mise à jour sont signées Ed25519.

Apple Silicon · macOS 14.2 minimum. Sans signature Developer ID ni notarisation Apple : le premier lancement peut nécessiter « Ouvrir quand même » dans les réglages macOS.
